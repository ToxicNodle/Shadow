## Install

From the repo root:

```bash
bash install.sh
```

This installs npm dependencies for both `wrapleads/` (server) and
`wrapleads/frontend/`, and seeds `wrapleads/.env` from `.env.example` if it
doesn't exist. See [`wrapleads/README.md`](wrapleads/README.md) for next steps
(database schema, ingesting data, starting the server).
